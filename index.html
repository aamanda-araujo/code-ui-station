Sua criatividade não tem barreiras, sua UI componentes também não deveria ter.
Um Design System desenhado para quem quer agilidade sem abrir mão da identidade. Aqui, você encontra componentes modernos, simples de integrar e totalmente personalizáveis para refletir o seu estilo único.

Componentes Disponíveis

  • Borda

    Definem os limites, o arredondamento (border-radius) e o estilo do contorno dos componentes da interface.

  • Botão

    Elementos interativos clicáveis utilizados para acionar ações específicas, como enviar formulários ou confirmar escolhas.

  • Box

    Contêineres estruturais básicos usados para agrupar, organizar e criar hierarquia visual entre diferentes elementos na tela.

  • Animação

    Efeitos de movimento e transições que fornecem feedback visual dinâmico e tornam a interação mais fluida.

  • Input

    Campos de entrada de texto ou dados onde o usuário interage digitando informações, essenciais para formulários e pesquisas
